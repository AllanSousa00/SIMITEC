# Contribuicao e Controle de Mudancas

Contribuicoes para a SIMITEC exigem autorizacao da organizacao responsavel. O repositorio nao e uma base aberta para redistribuicao ou reaproveitamento livre.

Antes de qualquer alteracao, a pessoa autorizada deve:

1. Trabalhar em branch propria e descrever claramente a finalidade da mudanca.
2. Nao incluir dados reais, segredos, artefatos de build ou arquivos locais.
3. Executar os testes aplicaveis e registrar limitacoes conhecidas.
4. Submeter revisao tecnica para alteracoes de autenticacao, permissoes, banco, e-mail, LGPD, pagamentos ou assinatura Android.
5. Obter aprovacao institucional para mudancas em termos, privacidade, retencao de dados, uso de imagem, identidade visual ou integracoes externas.

Ao enviar uma contribuicao autorizada, a pessoa declara que possui permissao para ela e concede a titularidade ou os direitos de uso necessarios para que a organizacao mantenha o projeto, conforme o instrumento escrito aplicavel.
